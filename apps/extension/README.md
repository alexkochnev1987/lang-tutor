# Word Collector — Chrome extension MVP

Локальный прототип расширения для Polski B1. Текущая версия: `0.1.1`.

## Что уже умеет

- добавлять слово, перевод и пример;
- сохранять слова в `chrome.storage.local`;
- показывать список сохранённых слов;
- удалять слова;
- сохранять выделенный текст через контекстное меню;
- входить через основной профиль Google;
- синхронизировать личный словарь с API приложения.
- открываться на локальной странице приложения.

## Запуск в Chrome

1. Открой `chrome://extensions`.
2. Включи «Режим разработчика».
3. Нажми «Загрузить распакованное расширение».
4. Выбери эту папку `apps/extension`.
5. Закрепи расширение на панели и открой popup.

Для входа в локальной разработке запусти веб-приложение на
`http://localhost:3000`, затем скопируй ID расширения из карточки расширения
в `chrome://extensions` и задай его в `apps/web/.env.local`:

```env
CHROME_EXTENSION_ID=полученный_id
```

После этого примени миграцию базы командой `pnpm db:migrate` и перезапусти
Next.js. В production уже используется `https://web-ecru-ten-90.vercel.app`.
`CHROME_EXTENSION_ID` должен совпадать с постоянным ID опубликованного расширения.

## Следующий этап

Для локальной разработки временно замени `APP_URL`, `API_URL` и
`host_permissions` на `http://localhost:3000`.
В backend задай `CHROME_EXTENSION_ID` равным ID расширения из `chrome://extensions`.
