# Промпт для автора оставшихся текстов Lang Tutor

Ты пишешь новые задания по чтению на польском для русскоязычного взрослого, который изучает польский в Lang Tutor. Работай в репозитории `lang-tutor` на ветке `content/reading-corpus-evaluation`. Начинай только после того, как владелец проекта подтвердит, что пилот прошёл независимое ревью.

## Объём работы

1. Прочитай `scripts/reading-drafts/README.md`, `scripts/reading-topic-plan.json`, `scripts/reading-sources.json`, `content/pl-b1-ru/curriculum.json` и `content/pl-b1-ru/vocabulary.json`.
2. Сопоставь дни 1–182 с полем `day` во всех черновиках `scripts/reading-drafts/*.json`. При исходном наборе из 57 текстов останется 125 дней. Для последующих пакетов учитывай дни, уже добавленные в репозиторий. Сообщи о пропусках или дубликатах, влияющих на выбранный диапазон.
3. За один проход напиши до 10 отсутствующих текстов. Начни с дней 54–63, если они ещё свободны. После каждого пакета остановись и передай его на независимое ревью. Продолжай со следующим пакетом после обратной связи.
4. Выбирай тему и жанр по плану дня. Сверяй лексику и грамматику с текущим и предыдущими уроками. Используй знакомые конструкции и объясняй новые слова через ситуацию. Ориентиры длины: A1 — 80–120, A2 — 130–200, B1 — 200–350 слов. Делай короткие абзацы с пустой строкой между ними, чтобы текст было удобно читать с телефона.

## Тексты и факты

Пиши естественным польским. Используй узнаваемые ситуации и меняй жанры по плану. Сохраняй разнообразие сюжетов, имён, мест и коммуникативных задач между пакетами. Подбирай регистр по ситуации и упрощай формулировки там, где формальность перегружает целевой уровень.

Для дней с указанным источником используй только факты из проверенной записи реестра. Перескажи их своими словами, сохрани метаданные источника по схеме проекта и явно обозначь вымышленные примеры. Если подходящего подтверждённого факта нет, выбери оригинальную вымышленную ситуацию. Правила, условия услуг и утверждения о реальных учреждениях требуют подтверждения. Образцы экзаменов используй как ориентир формата.

## Пять вопросов к каждому тексту

| ID | Что проверяет |
| --- | --- |
| `main-idea` | Понимание всего текста или его цели. Заголовка или первого предложения недостаточно для ответа. |
| `detail` | Один конкретный факт, который явно дан в тексте. |
| `cause` | Причину действия или события, которую подтверждает текст. |
| `inference` | Вывод по нескольким признакам или применение правила текста к новой ситуации. Прямой пересказ одного предложения проверяет поиск детали. |
| `vocabulary` | Значение слова или выражения в этой ситуации. Контекст даёт подсказку, которую нельзя получить из самого вопроса. |

Для каждого вопроса напиши три грамматически параллельных варианта. Все должны подходить по типу ответа и казаться возможными до внимательного чтения. В качестве неверных вариантов используй близкие детали из текста, перепутанное условие, время, мотив или роль. Исключи заведомо нелепые варианты, явные подсказки по длине, дословное совпадение только одного варианта с текстом, повтор одного проверяемого факта и предсказуемое чередование позиций ответа.

Проверь, что ровно один вариант полностью обоснован текстом. В черновике добавь `answer`, точно совпадающий с вариантом, `evidence` с дословной непрерывной цитатой и краткое объяснение на польском. Для вывода процитируй фрагмент, который содержит нужные признаки, и объясни связь между ними. Самостоятельно реши каждый вопрос как читатель и проверь, можно ли защитить любой из двух неверных вариантов.

## Что сохранить

- Новый JSON-файл в `scripts/reading-drafts/` со структурой `{"version":1,"status":"draft","texts":[...]}`. Используй поля `id`, `day`, `level`, `genre`, `title`, `text`, `questions` и, когда применимо, `source`. У каждого вопроса поля `id`, `skill`, `question`, `options`, `answer`, `evidence`, `explanation`. ID текста имеет вид `pl-b1.reading.day-054`.
- Отдельный файл для слепого ревью с полями `id`, `targetLevel`, `title`, `passage`, `questions`. У вопросов оставь только `id` (`q1`–`q5`), `question` и три `options` с полями `id` (`A`, `B`, `C`) и `text`. Используй формат пакетов `scripts/reading-blind/batch-*.json` с верхнеуровневым массивом `passages`. Сохраняй новый файл для каждого авторского пакета, например `scripts/reading-blind/batch-054-063.json`. В слепой файл входят только материалы, которые видит читатель.
- Запусти `node scripts/reading-pipeline.mjs validate --from 54 --to 63` для первого пакета. Для последующих пакетов проверяй свои диапазоны; для разрозненных дней можно проверять каждый день отдельно.
- Сообщи список дней, число текстов и вопросов, диапазон длин, результаты валидации и пути к двум файлам. Передай слепой пакет рецензенту отдельно. Проверку качества выполняет независимый рецензент, а черновики остаются в `scripts/reading-drafts/` до решения об интеграции.
