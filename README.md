# Polski B1

Подготовка к **государственному сертификационному экзамену по польскому
языку, уровень B1** (grupa dostosowana do potrzeb osób dorosłych).
15 минут в день, 182 дня, адаптивные упражнения и интервальное повторение.

Local-first: бэкенда нет, всё работает в браузере и офлайн.

```bash
pnpm install && pnpm dev
```

→ подробно в **[GETTING_STARTED.md](./GETTING_STARTED.md)**

---

## Что это

Приложение решает одну конкретную задачу: довести человека до сдачи
экзамена, а не «научить языку вообще». Отсюда два следствия, определяющие
всю архитектуру:

1. **Порог 50% считается по каждому модулю отдельно.** Провалил
   аудирование — провалил экзамен, даже со 100% в остальных четырёх.
   Поэтому система максимизирует **минимальный** модуль, а не средний балл.
2. **Целевая аудитория — русскоязычные.** Польский близок, и основная
   работа не «выучить», а «перестать переносить русский». 22 из 66
   грамматических правил помечены высоким риском интерференции — под них
   пишутся точечные дриллы.

## Структура

```
apps/web/            Next 16, App Router, output: 'export'
packages/engine/     FSRS + mastery + генератор занятия. Без единого 'pl'
packages/ui/         дизайн-система. ТОЛЬКО здесь живут Tailwind-классы
content/pl-b1-ru/    учебный контент — данные, не код
scripts/             валидаторы контента
tools/               tts-test.html — ручная проверка синтеза речи
docs/                документация
```

Проект спроектирован **многоязычным с первого дня**: три независимые оси —
что изучаем, на каком языке объясняем, к какому экзамену готовим.
Критерий приёмки — добавление нового языка не меняет ни строки в
`packages/engine`.

## Важные ограничения

Названы честно, потому что от них зависят обещания пользователю:

- **182 × 15 минут = 45,5 часа.** Cambridge оценивает путь с нуля до B1 в
  350–400 часов. Для русскоязычного цифра существенно ниже, но
  45 часов с абсолютного нуля до B1 — не обещание, которое можно давать.
  Отсюда диагностика на входе и три трека. Подробности —
  `docs/RESEARCH.md` §8
- **Аудирование** весит 40 баллов и имеет отдельный порог, а синтез речи
  не воспроизводит спонтанную речь. Это главный риск проекта
- **~800 слов, а не 2500.** Измерено, а не прикинуто: словарь в 2500 активных
  единиц стоит больше, чем весь бюджет курса. `docs/VOCABULARY.md` §3
- **Экзаменационные материалы Комиссии** можно использовать как эталон
  формата, но нельзя встраивать в приложение
